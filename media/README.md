# Stackyard media

Original pixel art made for Stackyard. It was drawn from code (no stock images, no AI image models, no third-party
assets) in the app's own palette (`--bg #1b1426`, `--acc #b79cff`, `--hot #ff9d3c`, …). It uses the same MIT license as the
repo, so it is safe to use in the templates, README, demo video and social posts.

Good for clickable images: e.g. the key in the drawer (show/hide + add item), or swapping `lamp-unlit` → `lamp-lit` on the "Light lamp" action.

### `pumpkin-steps/` (288×288, transparent PNG)

## How they are used, and the limits that were fixed

The three templates now use this art, including animated GIFs: bats circle the moon on the first card of
the Haunted House and the Ghost Story, the candle on the Study desk flickers, and the jack-o-lantern flickers on the
last pumpkin step. The editor uses `ghost-float` in the welcome and About dialogs and the candle on empty cards
(still sprites with reduced motion).

### Story art (generated by `npm run art`, do not edit by hand)

Drawn in code in `scripts/art/` for the longer stories, in the same style as the originals: the same 22-colour
palette (a test fails on any other colour), 4 px blocks for backgrounds (a 200×150 grid scaled ×4), 16 px blocks for
sprites and 12 px blocks for pumpkin pictures. `scripts/png.ts` writes the PNGs; the output is byte-for-byte
deterministic and a test fails if a file is out of date.

### `train/`: The Midnight Train (generated by `npm run art`, `scripts/art/train.ts`)

Eleven backgrounds (platform, the train arriving, carriage, window, the conductor's corridor, dining car, sleeper,
luggage van, the high bridge, home at dawn, the last stop), four characters drawn at 8 px blocks for more detail
(Mortimer, Mrs. Pell, Pip, Biscuit), five items (spectacles, music box, ticket, punched ticket, station clock) and
two looping animations: `steam.gif` (transparent, sits on the chimney) and `window-view.gif` (16 frames with
parallax: the moon and far hills stay still, a village drifts by, telegraph poles rush past).
Five colours were added to the palette for this stack: navy, light navy, dark velvet, lamp-lit wood and steam.

### `bestiary/`: The Halloween Bestiary (generated by `npm run art`, `scripts/art/bestiary.ts`)

Seventeen creature portraits at 8 px blocks (ghost, banshee, the Grim Reaper, Stingy Jack, vampire, zombie, mummy,
skeleton, witch, werewolf, goblin, kitsune, black cat, bat, spider, owl, and an animated will-o'-the-wisp) and
the cover (a candlelit library with the book open on a lectern). The designs are generic folklore, not copied from
films; in particular there is no studio-style "Frankenstein's monster".

### Derived files (generated, do not edit)

`gifs/candle-flicker-transparent.gif` is made from `gifs/candle-flicker.gif` by `npm run media`
(`scripts/make-media.ts`, using the small codec in `scripts/gif.ts`). The original has a solid dark background and
is delta-encoded, so the background could not simply be marked transparent: every frame is decoded, the background
colour is cleared, and the frames are re-encoded as full frames with "restore to background" disposal so the flame
leaves no trails. A test fails if the derived file is out of date. `ghost-float`, `bats-over-moon` and
`jack-o-lantern` also have solid backgrounds; add them to `DERIVED` if they need to sit on light cards.
The three templates use this art (see `scripts/make-templates.mjs`, which embeds the PNGs into `templates/*.json`).
Backgrounds are full-card image objects at the bottom layer, with a dark caption band at the bottom for story text.

| # | Limit | Status |
|---|---|---|
| 1 | Animated GIFs lost their animation (every upload was redrawn on a canvas). | **Fixed.** PNG and GIF uploads up to 256 KB (and 1600 px) are stored exactly as uploaded (`shouldKeepOriginal`). Bigger or other formats are still downscaled and re-encoded. |
| 2 | Lossy WebP smeared pixel edges. | **Fixed** by the same rule: small PNGs are never re-encoded. |
| 3 | Transparent sprites turned black when the browser could not write WebP (JPEG fallback). | **Fixed.** The fallback is PNG (`reencodeType`), which keeps transparency. |
| 4 | No per-card background field. | **Open.** Backgrounds are image objects at x 0, y 0, 800×600 on the bottom layer. They cannot be dragged away (they already fill the card), but a `background` asset on the card would be cleaner. |
| 5 | Text was always dark ink. | **Fixed.** Text has a *text style*: dark ink, light (with shadow), or light on a dark panel. The doctor hints when dark text sits on a picture. Schema v3, with a v2→v3 migration. |
| 6 | Images were smoothed when scaled. | **Fixed, per image.** Images have a *crisp pixels* flag that sets `image-rendering: pixelated` (on by default for kept PNG/GIF, off for photos, which look jagged when pixelated). Schema v3. |
