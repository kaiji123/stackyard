# Product: Stackyard

Stackyard brings back the late-'80s card-stack authoring tools: anyone can make interactive
software by placing text, images and buttons on index cards and linking them together.
Those tools died from platform lock-in. Stackyard exports a **single self-contained HTML file**
that runs offline in any browser, forever. The exported file is also the save file.

## Users
- Teachers making interactive lessons and quizzes
- Kids making their first games and stories
- Escape-room and puzzle makers (flags + inventory, no code)

## Hero use cases (templates)
1. Haunted House Escape Room
2. Choose-your-path Ghost Story
3. Tutorial: How to Carve a Pumpkin

Also shipped as examples: The Midnight Train (adventure) and The Halloween Bestiary (wiki).

## Non-goals (do not build)
- A scripting language. Actions are a no-code list chosen from dropdowns.
- Accounts, cloud sync, collaboration, marketplaces, AI generation.

## Naming and trademark rules
- Never use "HyperCard", "HyperTalk" or "Home stack" in product UI, code identifiers, repo name or assets.
  A factual history line in docs ("inspired by 1987 card-stack tools like HyperCard") is fine.
- Do not imitate Apple trade dress: no Chicago/Geneva fonts, no Mac OS 1-bit window chrome,
  no browse-hand cursor, no original tool palette icons. Use our own pixel style and OFL fonts
  (Silkscreen, VT323, Press Start 2P).
